# Source PDF (not included)

Place the annex of Marek Zdanowski, *Slavery in the Gulf in the First Half of the 20th Century: A Study Based on Records from the British Archives* (Warsaw: Askon, 2008), pp. 191–231, here as `ZDANOWSKI_slaved_data.pdf`.

The parser also accepts a PDF of the full book and skips to the annex. A PDF of the annex pages alone extracts more cleanly.

The book is under copyright, so neither the PDF nor the parsed table is distributed.
